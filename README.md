1. Jelaskan secara singkat apa itu JavaScript dan kegunaannya!
   => JavaScript merupakan bahasa pemrograman frontend yang berjalan di browser
   => Kegunaan javascript yaitu untuk membuat halaman web jadi lebih dinamis dan interaktif. Misalnya membuat tombol di siste/web yang dibangun itu bisa diklik/tekan, bisa memvalidasi form, membuat animasi yang berjalan dan semacamnyaa
3. Jelaskan secara singkat apa itu jQuery dan kegunaannya!
   => jQuery merupakan library javascript yang mempermudah penulisan kode
   => kegunaan jQuery yaitu dapat mempermudah/mempersingkat penulisan elemen HTML di kode, menyediakan efek animasi sederhana(hide(), show() dsb), simpelnyaa membuat kode menjadi lebih pendek dan mudah dibaca
5. Jelaskan perbedaan JavaScript dan jQuery!
   => JavaScript merupakan bahasa pemrograman utama yang bisa langsung berjalan di browser, sedangkan jQuery sendiri merupakan library tambahan dari javascript yang dipakai untuk mempermudah penulisan kode. Jadi bisa dibilang javascript adalah dasarnya, dan jQuery adalah alat bantu untuk menulis javascript menjadii lebih cepat, singkat dan mudah dimengerti/enak dilihat.
